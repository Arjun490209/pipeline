# 🌳 Microtree

**Microtree** is a CLI tool for creating structured microservice projects quickly and consistently. It helps developers organize their Node.js applications with a clean, maintainable folder structure.

## ✨ Features

- 🚀 Quickly scaffold microservice projects
- 📁 Generate an organized project structure
- 🟢 Built for Node.js and TypeScript
- 🛠️ Supports Express.js-based applications
- ⚡ Simple command-line interface
- 🧩 Designed to simplify project setup

## 📦 Installation

Run the following command to install Microtree globally:

```bash
npm install -g microtree
```

Or use it without a global installation:

```bash
npx microtree
```

## 🚀 Usage

Run Microtree from your terminal:

```bash
microtree
```

Follow the interactive prompts, if provided, to configure your project.

> Note: Available commands and prompts depend on the CLI functionality implemented in your package.

## 📂 Example Project Structure

A microservice project generated by Microtree could follow this structure:

```text
my-microservice/
├── src/
│   ├── config/
│   ├── controllers/
│   ├── middleware/
│   ├── models/
│   ├── routes/
│   ├── services/
│   ├── utils/
│   └── app.ts
├── .env
├── .gitignore
├── package.json
├── tsconfig.json
└── README.md
```

_The actual generated structure depends on your implementation._

## 🧰 Tech Stack

## 🎯 Why Microtree?

Setting up a new microservice project manually can be repetitive. Microtree aims to simplify the process by providing a consistent starting point, helping developers focus on building application features instead of repeatedly creating boilerplate files.

## 📋 Requirements

- Node.js

## 🛠️ Development

Clone your repository and install its dependencies:

```bash
npm install
```

Run the development script:

```bash
npm run dev
```

Build the TypeScript project:

```bash
npm run build
```

Run the compiled application:

```bash
npm start
```
